# Changelog

## 2026-09-21 — Auth-layout и страница профиля

### Исправлено

- **Auth-страницы рендерились в default-layout с сайдбаром.** `definePageMeta({ layout: 'auth' })` лежал в компонентах `modules/Auth/pages/*`, где макрос игнорируется. Перенесён в маршруты `src/pages/sign-in.vue`, `sign-up.vue`, `two-factor.vue`, `forgot-password.vue` — после выхода из аккаунта `/sign-in` открывается в центрированном auth-layout. Конвенция зафиксирована в `ARCHITECTURE.md`.

### Добавлено

- **Страница профиля `/profile`** (`modules/Profile`): личные данные (аватар-инициалы, имя, почта) и безопасность (смена пароля с валидацией, переключатель 2FA). Данные mock, локальный `ref` — см. `MOCKS.md`.
- Пункты меню профиля в шапке «Настройки профиля» и «Настройка 2FA» теперь ведут на `/profile` (ранее оба вели на `/settings` — настройки пространства). В breadcrumbs добавлен заголовок «Профиль».

## 2026-09-21 — Пересборка на Nuxt 4 + shadcn-vue

Проект пересобран с нуля на стеке из эталонного репозитория (Nuxt 4 / Vue 3 / TS / Tailwind v4 / shadcn-vue (reka-ui) / Pinia) с учётом findings UX-ревью первого прототипа.

### Исправлено из ревью (P0)

- **Универсальная action-модалка убрана.** Вместо неё — контекстные dropdown-меню на строках + отдельные модалки/диалоги под каждое действие.
- **Деструктивные подтверждения** для архивации, удаления, отзыва доступа, отключения учётной записи — с именем объекта и текстом последствий.
- **Степпер мастера защищён:** вперёд только после валидного шага, назад свободно; в edit-режиме все шаги доступны.
- **Живой счётчик состава** (был хардкод «7 из 8»), реальная фильтрация каталога, управление порядком товаров.
- **Чек-лист публикации вычисляется из данных**, а не захардкожен; кнопка «Опубликовать» объясняет, почему недоступна.
- **«Сохранить черновик»** реально сохраняет + тост, а не просто закрывает окно.
- **Рабочие фильтры и поиск** в подборках (по названию и slug) и сотрудниках (имя/почта).
- **Битые символы** кодировки первого прототипа отсутствуют — весь UI написан заново в UTF-8.

### Добавлено из ревью (P1)

- Раздел **Обзор**: метрики, быстрые действия, последние подборки, ожидающие активации сотрудники.
- Вкладка **Архив** с восстановлением подборок.
- Раздел **Настройки** пространства + уведомления + опасная зона.
- **Popover уведомлений** с «Прочитать всё», меню профиля, переключатель пространств с созданием нового.
- **Empty states** во всех списках, пагинация, тосты vue-sonner.
- Типографика от 12px, touch-targets ≥ 40px, focus-visible, aria-атрибуты.
- Auth: `/forgot-password`, resend 2FA с таймером, лимит попыток, живые требования к паролю, состояния приглашения (истёк/использован).

### Известные ограничения (до backend)

- Нет персистентности — данные в памяти вкладки.
- Ролевая модель описана в данных, но не ограничивает UI.
- Нет реальной отправки писем и 2FA.
